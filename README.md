# 🚀 Premium php Developer Portfolio

Welcome to the repository of my personal portfolio website! This project is designed to stand out, ditching the standard generic templates for a **highly interactive, cinematic, and premium user experience**. 

It serves as a digital resume and project showcase for my journey as a **Php Developer** specializing in Web Development.

🔗 **[View Live Portfolio Here](https://hardik-portfolio-three-virid.vercel.app)**

## ✨ Key Features & Highlights

This portfolio isn't just a static page; it's an experience. Here are the core UI/UX features built into it:

* **🎬 Cinematic Preloader:** A custom fluid text-fill animation that locks scrolling until the portfolio is fully loaded.
* **🎥 Video/Image Hero Toggle:** A dynamic hero section that seamlessly transitions between a high-quality profile image and an introductory video reel using pure JavaScript.
* **🪪 Elastic Hanging ID Card:** A unique "Persona" section featuring a 3D ID card that drops from the top of the screen with a physics-based GSAP elastic bounce effect.
* **📍 Advanced Pinned Scrolling ("My Process"):** Utilized GSAP ScrollTrigger to pin the screen in place while the user scrolls through a 6-step automation and development workflow, highlighting active cards dynamically.
* **📊 Animated Skill Bars:** Clean, minimal progress bars that animate from 0% to their respective values only when they enter the user's viewport.
* **🌗 Dynamic Smart Navbar:** A sticky navigation bar that uses collision detection to automatically switch text colors (Black/White) depending on whether it is hovering over a dark or light section of the website.
* **📧 Fully Functional Contact Form:** Integrated with Formspree to receive direct emails without exposing the backend server.

## 🛠️ Tech Stack & Architecture

This project was built from scratch without any heavy frontend frameworks to ensure lightning-fast load times and pure DOM manipulation control.

* **Markup:** HTML5 (Semantic & Accessible)
* **Styling:** CSS3 (Custom Variables, Flexbox, CSS Grid, Fluid Typography)
* **Interactivity:** Vanilla JavaScript (ES6+)
* **Animation Engine:** GSAP (GreenSock) & GSAP ScrollTrigger
* **Icons:** Phosphor Icons
* **Backend Form Routing:** Formspree
* **Hosting/Deployment:** Vercel

## 🚀 How to Run Locally

If you want to explore the code or run this on your local machine, follow these steps:

1. Clone the repository using your terminal:
   git clone https://github.com/jaspreet55/jaspreet-portfolio.git

2. Open the folder in your favorite code editor (e.g., VS Code).
3. Launch a Local Server:
   - If you are using VS Code, install the "Live Server" extension.
   - Right-click on index.html and select "Open with Live Server".
4. The portfolio will automatically open in your default browser at http://127.0.0.1:5500/index.html.
